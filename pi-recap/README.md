# recap

A small [pi](https://github.com/earendil-works/pi-coding-agent) extension that
catches you up when you sit back down. Step away, and once you have been quiet
long enough it writes a recap of the session into the transcript, waiting for
you — written by whichever cheap model is next in the rotation. No keystroke
needed to trigger it; it is already there when you look.

```text
╭  Recap ─────────────────────────────────────────────────────────────────────────╮
│                                                                                 │
│ Inspected pi-recap package.json and index.ts; extension recaps sessions    │
│ via a cheap model after stepping away.                                          │
│                                                                                 │
│  Next: Awaiting your direction on next steps for the extension.                │
│                                                                                 │
╰──────────────── generated by DeepSeek V4 Flash 0731 (Baseten) at 12:43pm, Sep 6 ╯
```

`Recap` rides the top border and the content sits on its own background, the
same shape `pi-tool-display` gives a user message. The attribution rides the
bottom rule, the way `pi-context-footer` sets status items into the prompt
border.

## Styles

```text
/recap style          report the current style
/recap style frame    the box above (default)
/recap style clean    the same content, flush left, nothing drawn around it
```

Style is read at render time, so switching redraws recaps already in the
transcript rather than waiting for the next one.

Clean looks like this:

```text
 Recap: Inspected pi-recap/package.json and confirmed index.ts is 638
        lines, after reviewing the package setup for the extension.
 Next: Ready to continue working on the extension.
generated by DeepSeek V4 Flash 0731 (Baseten) at 9:49am, September 6
```

Markers and labels sit flush left; each block's wrapped lines hang under where
its own text began, so the indent resets between blocks. The markers default
to Nerd Font's filled and hollow circle — a designed pair from one family, so
they stay the same optical size as each other whatever the terminal does with
them — and can be swapped for any two glyphs with `/recap icons`.

A blank row separates the two blocks, so they read as two — in both styles.

Colors come from the theme's custom-message set — `customMessageLabel` for the
bold labels, `customMessageText` for the prose — on the *user-message*
background, so a recap sits on the same ground as the messages around it. That
background is also the darker of the two, which the prose needs: it takes the
text from 4.15:1 to 4.74:1 and the label from 5.79:1 to 6.60:1.

The recap line carries the work and where it stands. The `Next:` line is only
what happens after it — what is wanted from you, or what would happen if you
said go.

## It scrolls with the rest of the session

The recap is written into the transcript as its own entry, the same way pi
renders any other message — so it scrolls up into history like the rest of
the session instead of sitting pinned above the prompt. It does not disappear
when you start working, and a new recap does not replace the last one; each
away period gets its own entry.

## What counts as "away"

No keystrokes for five minutes, by default. That is a proxy, and worth being
explicit about: pi does not hand extensions the terminal's focus events, so an
extension cannot tell "walked away" from "sat and read the whole run". The only
presence signal available is input to the editor, so a long run you watched
end-to-end and then typed after will still produce a recap.

The away clock runs from your last keystroke, never from the agent's activity —
a long unattended run is exactly the case a recap is for, so letting the
agent's own output refresh the clock would suppress the recap that matters
most. A check that lands while the agent is still working is skipped and
re-armed when it settles, and never fires within eight seconds of the agent
going quiet, so a run you watched to the end is not immediately talked over.

If the timer could not produce a recap — the agent was still busy, or the call
failed — the first keystroke after the silence tries once more.

The recap is skipped when:

- the agent is still working — `ctx.isIdle()` is false, so the screen is
  already telling you what is happening
- the prompt already has a draft in it, which means you never really left
- nothing was added to the session while you were gone
- a recap is already being generated

## The rotation

Each recap uses the next model in this order, and says which one wrote it:

1. DeepSeek V4 Flash
2. GLM 5.3 Flash
3. Gemini 3.8 Flash
4. GPT-5.6 Luna
5. Claude Haiku 4.5

Models are matched against the catalogue by id pattern rather than by
`provider/id`, so a model that arrives under a different provider name still
resolves, and an entry that resolves to nothing — or that has no configured
auth — drops out of the rotation quietly instead of breaking it. The call is
made through `ctx.modelRegistry.complete()`, which resolves provider auth
itself.

The position in the rotation persists to `config.json` (see
[Configuration](#configuration)) and advances after every recap, so a session
that produces only one recap before you restart pi still moves on to the next
model rather than starting over at DeepSeek each time.

Nothing about a recap is load-bearing, so failure is silent: a gateway that is
down, unauthenticated, or slower than the 30s timeout costs the session
nothing and leaves no widget. Use `/recap now` to see the error.

## What the model is shown

The whole session, one line per entry, with a marker where you stopped typing,
so the recap can cover what the session has been about while favouring the part
you missed. Not the raw transcript: tool arguments and
results are the bulk of a session and almost none of what a recap needs, so
each entry collapses to a line naming what happened — what the agent said,
which tools it ran, which failed, whether the context was compacted. The digest
is capped at 14,000 characters, keeping the tail, since the newest activity
matters most.

The reply is asked for as two labelled lines and the renderer splits it on the
`Next:` label. The prompt asks for about 200 characters on the recap line and
100 on the next, with 500 as a hard ceiling the renderer clamps to on a word
boundary — a cheap model told to be brief will sometimes write five sentences
anyway, so the limit is enforced here rather than trusted.

It is also told to write for scanning: what the work was rather than every
step, one or two concrete anchors at most, no parentheticals, no listing every
file touched, and no quoting counts unless the number is the point. Asking it
to "name real things" instead produced accurate recaps that were tiring to
read.

The token budget is 2,000: every model in the rotation is a reasoning model and
thinking is drawn from the same budget, so a smaller cap bought recaps that
stopped mid-sentence.

## Usage

```text
/recap                        toggle
/recap on                     enable
/recap off                    disable
/recap now                    recap now, without waiting
/recap style                  report the current style
/recap style frame            box it, or `clean` for flush left
/recap icons                  report the current markers
/recap icons <recap> <next>   set the recap and next markers
/recap icons reset            back to the default circles
/recap after 15               set the away threshold, in minutes
/recap models                 show the rotation and which model is next
```

## Configuration

`style` and `icons` persist across sessions, written to
`<agent dir>/pi-recap/config.json` (the agent dir is `~/.pi/agent` unless
`PI_AGENT_DIR` says otherwise) — deliberately not under
`<agent dir>/extensions/pi-recap/`, since that path is a symlink into
this repo's checkout and writing there would land config changes in git.

Each marker in `icons` is a literal glyph, or a codepoint written `U+F11EA` or
`f11ea` — useful for a Nerd Font icon that's awkward to type or paste
directly. The file looks like:

```json
{
  "markers": { "recap": "", "next": "" },
  "style": "frame"
}
```

Missing or invalid fields fall back to the built-in defaults, and a missing or
unreadable file is not an error — it just means nothing has been customized
yet. `after` (the away threshold) is deliberately not part of this file — see
below.

`after` accepts fractions, which is how to exercise the automatic path without
waiting five minutes: `/recap after 0.2` recaps roughly twelve seconds
after you stop typing. The threshold is session state — a new pi session is
back to five minutes.
